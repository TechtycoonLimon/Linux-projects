SysGuard Monitor is a Bash-based Linux system monitoring tool designed to help users monitor important system resources in real time through a simple command-line interface. The project displays CPU usage, memory usage, disk usage, running processes, internet connection status, and system information using colorful progress bars and an interactive dashboard.

The system also includes features such as usage alerts, log file generation, and process monitoring to help users quickly identify system performance issues. The project is lightweight, easy to understand, and can run on Linux environments or cloud platforms like Google Colab with minimal setup.

This project was developed to demonstrate practical use of Bash scripting, Linux commands, process management, file handling, loops, conditions, and automation techniques in a real-world system monitoring application.
